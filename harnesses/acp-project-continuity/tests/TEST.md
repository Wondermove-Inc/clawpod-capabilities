# ACP Project Continuity test evidence

The core suite covers mandatory onboarding and discoverability, separate lineages, context mismatch, no-fallback resolution, CAS revisions, leases, rotation/close, corruption, permissions, path escape, symlinks, and secret-like input/state rejection. The E2E suite installs the generated Registry pair into temporary roots and runs the installed Harness without network, credentials, or live agent state.

Commands are reported in the completion summary.
