ClawPod Node 0.3.4는 `perf/browser-computer-tools` 브랜치의 브라우저·원격 컴퓨터 개선을 포함한 릴리즈입니다.

## 변경 내용

- 최신 브랜치의 Agent 실행 파일을 새로 빌드해 Node 앱에 포함했습니다. 이전 0.3.3의 Agent 실행 파일을 재사용하지 않았습니다.
- 원격 컴퓨터 도구의 반복 화면 전송, 같은 위치 연속 클릭, 키 이름 처리와 입력 오류 복구를 개선했습니다.
- 브라우저의 로딩 중 탭 처리와 도구 안내 개선을 포함합니다.
- 기존 다중 연결, 연결 이름·삭제, 한글/영어 UI, 컴퓨터 설정 분리 기능을 유지합니다.

## 설치 파일

- macOS Apple Silicon: `ClawPod-Node-0.3.4-darwin-arm64.pkg`
- Linux x64: `ClawPod-Node-0.3.4-linux-x64.deb`
- Windows x64: `ClawPod-Node-0.3.4-win32-x64.exe`

각 설치 파일의 SHA-256 체크섬과 빌드 출처·검증 범위를 기록한 `release.json`을 제공합니다.

## 검증 범위

- macOS ARM64 앱과 설치 파일은 맥 스튜디오에서 Developer ID로 서명했습니다. PKG의 Apple 공증·스테이플링·Gatekeeper 검증을 완료했습니다.
- Mac의 서명된 런타임, 앱 IPC, 단일·다중 연결, 분리된 시험 창에서 화면 캡처·Unicode 붙여넣기/입력·클릭/드래그·키 누름 취소를 확인했습니다. 실제 설치 업그레이드·로그인 시작과 운영 Gateway 페어링은 시험하지 않았습니다.
- 브라우저·원격 컴퓨터 관련 TypeScript 테스트 186개 통과.
- Node 기본 테스트 61개 통과. 브라우저·Linux 네이티브·연결 프로토콜 테스트는 별도로 수행했습니다.
- 실제 Linux 설치 파일의 브라우저 UI 테스트 7개, 새 Linux 네이티브 도구의 X11 테스트 3개 통과.
- 네트워크가 차단되고 Node.js가 사전 설치되지 않은 Debian 12에서 0.3.3 → 0.3.4 업그레이드, 기존 설정·인증 보존, 실행 중 앱 재시작, 단일·다중 연결, 제거 후 사용자 상태 보존 확인.
- 배포 대상 세 플랫폼의 내장 Agent dist·의존성 파일을 이번 소스 빌드와 대조하고 버전·락파일 해시를 확인했습니다.

Windows 실제 실행·설치와 게시자 서명은 검증하지 않았습니다. 이번 릴리즈에는 macOS Intel 설치 파일을 포함하지 않습니다. 능력 카탈로그·스킬·하네스는 이번 릴리즈에서 변경하지 않습니다.
