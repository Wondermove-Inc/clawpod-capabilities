## ClawPod Node 0.3.1

0.3.0의 다중 Agent 연결 기능을 유지하면서, 연결 관리 화면을 정리한 릴리즈입니다.

### 변경 사항
- 드롭다운 대신 연결 목록을 표시하여 등록한 Gateway와 로컬 실행 상태를 함께 확인할 수 있습니다.
- 선택한 연결의 상태, 시작·재연결·중지 버튼과 설정을 한 영역에 배치했습니다.
- 컴퓨터 공통 자동 시작·데스크톱 권한을 별도 영역으로 구분했습니다.
- 기존 연결의 설정·고급 옵션·도움말은 필요할 때 펼칩니다. 신규 연결은 설정을 바로 입력할 수 있습니다.
- 상태 갱신 중 키보드 포커스와 입력값을 유지하고, 접힌 설정에 입력 오류가 있으면 해당 영역을 펼칩니다.
- 좁은 화면에서는 목록과 설정을 세로로 표시합니다.

### 기존 동작 유지
- 연결·인증·페어링·포트 할당·프로세스 실행 방식은 0.3.0과 동일합니다.
- 설정 저장은 선택한 연결과 공통 로그인 자동 시작을 함께 저장하며, 실행 중인 선택 연결을 재시작합니다. 화면에 이 동작을 명시했습니다.
- `running`은 로컬 프로세스 상태입니다. 실제 Gateway 연결·페어링은 Agent Control UI에서 확인합니다.

### 설치 파일
- Linux x64: `.deb`
- Windows x64: `.exe`
- macOS Apple Silicon: `darwin-arm64.pkg`
- macOS Intel: `darwin-x64.pkg`

각 파일의 SHA-256은 함께 첨부한 `.sha256` 및 `release.json`에서 확인할 수 있습니다.

### 검증 범위
- Node 시험 54건, 패키지에서 추출한 UI의 브라우저 시험 5건 통과.
- Linux: 오프라인 0.3.0 → 0.3.1 업그레이드, 실행 중 앱 재시작, 설정·인증 보존, 단일·다중 연결 프로토콜, 제거 검증.
- macOS ARM64·Intel: Developer ID 서명, Apple 공증, 스테이플링, Gatekeeper 및 설치 파일 추출 검증. Intel 실행 검증은 Apple Silicon Mac의 Rosetta를 사용합니다.
- Windows: 설치 파일 추출과 페이로드 일치 검증. 실제 Windows 실행 및 게시자 서명은 이번에 수행하지 않았습니다.
- Mac 신규 설치·로그인 자동 시작·설치 앱 업그레이드/제거·실제 데스크톱 조작·운영 Gateway 페어링은 이번 릴리즈 검증 범위에 포함하지 않습니다.

이번 배포는 설치 파일 릴리즈입니다. 능력 카탈로그·Skill·Harness는 업데이트하지 않았습니다.
