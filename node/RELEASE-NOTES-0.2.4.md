# ClawPod Node 0.2.4

원격 컴퓨터의 화면 요소를 더 정확하게 조회하도록 개선했습니다.

- **깊게 중첩된 화면 요소 조회:** macOS·Windows·Linux에서 고정된 깊이 제한으로 입력칸이나 버튼이 누락되는 문제를 개선했습니다.
- **Mac 요소 이름 확인:** 제목이 비어 있으면 설명에 있는 이름을 사용해 검색합니다.
- **일부 결과 구분:** 조회 한도나 앱의 접근성 오류가 있으면 일부 결과라는 사실과 이유를 에이전트에 전달합니다. 빈 결과를 곧바로 “요소 없음”으로 판단하지 않도록 안내했습니다.
- **사용 안내 정리:** 반환된 이미지 좌표, 키 입력의 `text` 인자, 요소 이름·값 검색 방법을 명확히 했습니다.

사용 중인 운영체제와 CPU에 맞는 설치 파일로 업데이트하세요. 저장된 연결 설정과 노드 식별정보는 유지됩니다. 조회 결과의 새 정보를 사용하려면 ClawPod Agent도 함께 업데이트해야 합니다.

기존 화면 캡처·마우스·키보드 조작과 에이전트 파드의 `computer` 도구는 유지됩니다. 설치된 브라우저를 GUI로 조작할 수 있으며 Chrome 설치가 필수는 아닙니다.

플랫폼별 검증 범위는 저장소의 Node 검증 문서를 참고하세요.
