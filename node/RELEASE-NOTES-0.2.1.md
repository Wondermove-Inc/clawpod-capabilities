# ClawPod Node 0.2.1

**연결한 컴퓨터의 CLI 작업을 실행부터 결과 확인까지 이어갈 수 있도록 개선했습니다.** SSH 서버 없이 ClawPod Node 연결을 사용합니다.

## 달라진 점

- **명령 실행 오류 수정:** 정상적인 네이티브 실행 파일과 셸 명령이 준비 단계에서 잘못 거절되던 문제를 수정했습니다.
- **백그라운드 작업 관리:** 실행 중인 명령의 진행 상태와 출력을 확인하고, 같은 실행에 추가 입력을 보내거나 취소할 수 있습니다.
- **터미널 프로그램 지원:** 입력을 기다리는 프로그램도 PTY로 실행해 대화를 이어갈 수 있습니다.
- **긴 작업과 결과 처리 개선:** 명령 제한시간과 통신 대기시간을 구분하고, 한글·영문 출력과 오류·종료 상태를 함께 전달합니다.
- **워커 후속 작업 연결:** 워커가 시작한 백그라운드 명령의 결과가 해당 워커로 돌아가 후속 작업을 이어갑니다. 출력 없이 성공한 명령도 처리합니다.
- **실행 정리:** 취소·세션 리셋·노드 연결 종료 시 해당 실행을 정리합니다. 재연결만으로 명령을 무작정 다시 실행하지 않습니다.

기존 원격 GUI, 브라우저 경로, 사설 IP·Tailscale 연결, 설정과 기기 정보는 유지합니다.

## 업데이트 방법

**Gateway의 Agent와 컴퓨터의 ClawPod Node를 모두 업데이트해야 새 CLI 동작을 사용할 수 있습니다.** Node 앱만 업데이트하면 이전 Agent에는 새 실행 관리 기능이 생기지 않습니다.

1. 이번 CLI 패치를 포함한 Agent 이미지를 배포합니다.
2. 아래에서 컴퓨터에 맞는 설치 파일을 받아 기존 앱을 업데이트합니다.
3. ClawPod Node를 열고 연결을 확인합니다. 에이전트는 대상 `node`를 지정한 `exec`로 실행하고, 반환된 `sessionId`를 `process`에 전달해 후속 작업을 합니다.

| 컴퓨터 | 설치 파일 |
| --- | --- |
| macOS Apple Silicon | `ClawPod-Node-0.2.1-darwin-arm64.pkg` |
| macOS Intel | `ClawPod-Node-0.2.1-darwin-x64.pkg` |
| Windows x64 | `ClawPod-Node-0.2.1-win32-x64.exe` |
| Linux x64 — glibc 2.36 이상 | `ClawPod-Node-0.2.1-linux-x64.deb` |

Mac 업데이트 후 GUI 권한이 거부되면 시스템 설정에서 현재 응용프로그램의 **ClawPod Node**를 다시 확인하세요. CLI 사용에는 화면·입력 권한이 필요하지 않습니다.

## 배포 상태

이 버전은 프리뷰입니다. Mac 앱은 임시 서명이며 Apple 공증·Developer ID 서명, Windows 게시자 서명은 적용하지 않았습니다. Linux는 최종 DEB를 오프라인 환경에 설치해 검증했고, Mac Apple Silicon은 최종 PKG에서 꺼낸 앱의 런타임으로 명령·PTY 입력·종료 정리를 검증했습니다. Windows와 Intel Mac은 패키지 검증을 완료했으며, 해당 OS·CPU에서의 실제 실행 검증은 아직입니다.
