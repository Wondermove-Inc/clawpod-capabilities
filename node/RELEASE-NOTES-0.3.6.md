ClawPod Node 0.3.6은 UI/UX 보완 릴리즈입니다. 기존 연결·인증·설정 저장과 런타임은 유지합니다.

- Gateway 입력 예시를 `ws://192.168.0.100:18789`로 변경했습니다. 입력값이나 ws/wss 연결 정책을 바꾸지 않습니다.
- 언어 선택을 한국어 | English 토글로 바꿨습니다. 기존 저장·오류 처리와 키보드 조작을 유지합니다.
- 연결 준비 안내를 데스크톱 권한 허용 → 에이전트가 제공한 Gateway 주소·토큰 입력 순서로 정리했습니다.

설치 파일: macOS ARM64, Linux x64, Windows x64. Intel Mac은 포함하지 않습니다.
Mac 설치 파일은 Developer ID 서명·Apple 공증·스테이플링을 적용합니다. 체크섬과 검증 범위를 기록한 release.json을 함께 제공합니다.

검증: 기본 테스트 재실행 61개 통과(기본 생략 13개), 설치 파일 기준 Chromium UI 8개 통과, Linux 실제 0.3.5→0.3.6 업그레이드 및 설정·인증 보존, 세 플랫폼 파일 대조. 첫 기본 테스트 실행에서 기존 병렬 종료 호출 순서 검증 1건이 실패했으며 제품·테스트 코드 수정 없이 재실행 통과했습니다.

기존 Agent 런타임, Node.js 24.15.0, 의존성과 네이티브 구현은 그대로입니다. Windows 실제 설치·실행과 게시자 서명, Mac 실제 설치·업그레이드·로그인 시작, 운영 Gateway 페어링 및 새로운 데스크톱 입력 시험은 이번에 수행하지 않았습니다.
