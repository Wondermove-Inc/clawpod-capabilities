ClawPod Node 0.3.5는 설정 화면의 UI/UX를 개선한 릴리즈입니다. **0.3.4의 Agent 런타임·Node.js·의존성·네이티브 기능은 그대로 유지합니다.**

## 변경 내용

- 어두운 사이드바와 카드 구성으로 화면을 개편하고 기존 ClawPod 앱 아이콘을 사용합니다.
- 연결 목록 검색, 연결 개요/설정, 데스크톱 권한, 일반 설정을 구분합니다.
- 첫 연결 입력과 모바일 화면 배치를 개선합니다.
- 권한 재확인 실패를 연결 개요에도 표시하고, 실패 시 성공 강조를 제거합니다.
- 기존 연결·인증·저장·실행 제어·권한 요청 방식은 유지합니다. 저장과 연결 시작, 자동 시작 설정 저장도 기존처럼 분리됩니다.

## 설치 파일

- macOS Apple Silicon: `ClawPod-Node-0.3.5-darwin-arm64.pkg`
- Linux x64: `ClawPod-Node-0.3.5-linux-x64.deb`
- Windows x64: `ClawPod-Node-0.3.5-win32-x64.exe`

각 설치 파일의 SHA-256과 빌드 출처·검증 범위를 기록한 `release.json`을 제공합니다. 이전과 동일한 공개 프리릴리즈 방식이며 Intel Mac 설치 파일은 포함하지 않습니다.

## 검증

- Node 기본 테스트 61개 통과. 설치 파일 기준 Chromium UI 테스트 8개 통과.
- 네트워크가 차단되고 Node.js가 없는 Debian 12에서 실제 0.3.4 → 0.3.5 업그레이드, 실행 중 앱 재시작, 설정·인증 보존, 단일·다중 연결, 제거 후 사용자 상태 보존 확인.
- 세 플랫폼 모두 기존 런타임·네이티브 파일 보존과 새 UI 소스 일치를 파일 해시로 검증했습니다. Mac 외부 앱 서명은 새 패키지에 맞춰 갱신했습니다.
- Mac Studio에서 Developer ID 앱/설치 파일 서명, Apple 공증·스테이플링·Gatekeeper 검증을 완료했습니다. 서명된 런타임, 앱 IPC/권한 상태 조회, 단일·다중 연결 시험을 통과했습니다.
- 세 설치 파일을 추출해 포함된 파일을 대조했습니다.
- 독립 적대리뷰에서 발견한 UI 오류를 보완하고 재검토했습니다.

실제 Windows 설치·실행과 게시자 서명, Mac의 실제 설치 업그레이드·로그인 시작, 운영 Gateway 페어링은 검증하지 않았습니다. 기존 0.3.4 이후의 Agent 코어 변경이나 새 네이티브 기능은 이 UI 릴리즈에 추가하지 않습니다. 능력 카탈로그·스킬·하네스 및 이전 릴리즈는 변경하지 않습니다.
