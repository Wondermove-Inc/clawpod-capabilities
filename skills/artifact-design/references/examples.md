# Worked examples

## 1. Inline HTML artifact (normal case)

User: "정리해서 보고서로 줘" after a pricing analysis.

Design plan (written before code):

- **Subject / job**: three pricing tiers, two proposed changes; the page exists so a product lead can decide by 12 September.
- **Treatment**: utilitarian. A decision memo, not a landing page.
- **Color**: ground `#F7F6F2`, surface `#FFFFFF`, ink `#1D1F24`, muted `#5C6070`, accent `#1F5F8B` (a cool ink-blue that reads as "finance" without going corporate); dark set in the skeleton.
- **Type**: display "Iowan Old Style" → Georgia (numbers look settled in an old-style serif); body "Avenir Next" → Segoe UI → Pretendard; mono for the SKU codes.
- **Layout**: a header with eyebrow + one-sentence decision ask, a three-column tier grid, one comparison table in a scroll container, a closing "decision needed" card.

Message payload:

```json
{
  "content": "Q3 가격 검토 보고서를 정리했습니다. 12일까지 결정이 필요한 두 가지 변경안을 마지막 카드에 모았습니다.",
  "artifacts": [
    {
      "identifier": "q3-pricing-review",
      "type": "html",
      "title": "Q3 Pricing Review",
      "content": "<!doctype html><html lang=\"ko\"><head>…</head><body><main>…</main></body></html>"
    }
  ]
}
```

## 4. File output → save first, then reference

The deliverable already exists as a workspace file (for example an exported HTML report generated by another capability).

1. Save:

```http
POST /internal/chat-rooms/{roomId}/artifacts
{
  "identifier": "ocr-comparison-batch-17",
  "type": "html",
  "title": "OCR Comparison · Batch 17",
  "content": "<!doctype html>…",
  "expectedVersion": 1
}
→ 200 { "identifier": "ocr-comparison-batch-17", "version": 2 }
```

(A `409` here means someone saved version 2 already: re-read, merge, resend with `expectedVersion: 2`.)

2. Send the message with a pointer only:

```json
{
  "content": "배치 17 OCR 비교 리포트를 갱신했습니다.",
  "artifact_refs": [
    { "identifier": "ocr-comparison-batch-17", "version": 2 }
  ]
}
```

## 5. What not to do

```json
{
  "content": "```html\n<!doctype html>…\n```\n\n또는 파일: /workspace/report.html"
}
```

Both render as plain text. No card, no panel, no version. Move the content into `artifacts` (or save and use `artifact_refs`).

## 6. Splitting an over-long deliverable

A 320,000-character page exceeds the 200,000 limit. First remove embedded raster data URIs (replace with inline SVG/Canvas or a text note). If still too long, split by section into at most five artifacts with distinct identifiers (`audit-2026q3-part-1`, `…-part-2`), each a complete self-contained document, and say in the body how they relate.
