# Engineering extension pack

Add only the fields for the selected common family.

1. **Delegation/task:** repository, component, change boundary, test expectation, compatibility constraints.
2. **Peer help:** minimal reproduction, environment, logs/errors, suspected layer, attempted fixes.
3. **Upward status/decision:** architecture or delivery impact, alternatives, migration cost, technical-debt effect.
4. **Blocker/escalation:** failing dependency or check, release impact, rollback/containment option, required technical decision.
5. **Handoff:** branch/change state, local or CI results, unfinished edits, environment assumptions, next safe command or inspection.
6. **Review/approval:** diff/PR reference, purpose, linked issue, tests and checks, risk, review focus, rollback, merge/release criteria.
7. **Incident update:** affected component/version, deployment correlation, diagnostics, mitigation status, service-owner coordination.
8. **Completion/closure:** merged or delivered artifact, exact verification, compatibility result, rollout state, residual follow-up.
9. **No-response follow-up:** blocked review/deploy, stale-check risk, alternate reviewer/owner, cutoff or reschedule decision.

Do not send only a PR or ticket URL. Include purpose, verification, risk, and the requested review decision.
