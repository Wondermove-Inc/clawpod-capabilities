## Matrix columns

For each applicable rule, record:

- Rule ID;
- applicable file or evidence;
- requirement status: met / partial / unmet / not applicable;
- direct evidence;
- gap or remediation.

Provisional rules must remain provisional. A provisional rule can guide inspection but cannot become a confirmed completion gate without official source or measurement.
