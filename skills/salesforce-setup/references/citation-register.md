# Setup Citation Register

Use this portable register when the active workspace does not provide a stronger source-of-truth register.

In this repository, canonical Salesforce source-of-truth rows already cover `sf org display`, `sf org list`, `sf org list metadata`, `sf org list limits`, `sf sobject describe`, and `sf data query`. The setup-only `sf org login web` and capability-probe `sf org list metadata-types` URLs below are official Salesforce command references checked against local help, but they are not canonical SOT rows until a separately approved SOT update adds them.
