# Org Inspection Citation Register

Use this portable register when the active workspace does not provide a stronger source-of-truth register.

In this repository, canonical Salesforce source-of-truth rows already cover `sf org display`, `sf org list metadata`, `sf org list limits`, `sf sobject describe`, and `sf data query`. The `sf org list metadata-types` URL below is an official Salesforce command reference checked against local help, but it is not a canonical SOT row until a separately approved SOT update adds it.

| Claim | Official URL | API Version / Release | Date Confirmed | Method | Limitation |
| --- | --- | --- | --- | --- | --- |
| `sf org display` provides target org identity evidence and supports `--target-org`, `--api-version`, and `--json`. | https://developer.salesforce.com/docs/platform/salesforce-cli-reference/guide/cli_reference_org_display.html | API version not applicable; command accepts `--api-version`; local CLI `@salesforce/cli/2.141.6` help checked | 2026-08-02 | Official documentation and local `sf org display --help` | Output can contain sensitive token/client fields and must be redacted. |
| `sf org list metadata-types` and `sf org list metadata` provide metadata type/component inventory. | https://developer.salesforce.com/docs/platform/salesforce-cli-reference/guide/cli_reference_org_list_metadata-types.html ; https://developer.salesforce.com/docs/platform/salesforce-cli-reference/guide/cli_reference_org_list_metadata.html | API version not applicable; commands accept `--api-version`; local CLI `@salesforce/cli/2.141.6` help checked | 2026-08-02 | Official documentation and local command help | Inventory requires org permissions and does not prove runtime behavior or mutation safety. `org list metadata` is covered by a canonical SOT row; `org list metadata-types` is not yet a canonical SOT row in this repository. |
| `sf sobject describe` displays metadata for standard/custom objects and can use Tooling API for Tooling API objects. | https://developer.salesforce.com/docs/platform/salesforce-cli-reference/guide/cli_reference_sobject_describe.html | API version not applicable; command accepts `--api-version`; local CLI `@salesforce/cli/2.141.6` help checked | 2026-08-02 | Official documentation and local `sf sobject describe --help` | Describe output is scoped to target org, API version, and user permissions. |
| `sf data query` executes SOQL, supports `--target-org`, `--api-version`, `--json`, and `--use-tooling-api`, and recommends Bulk API for more than 10,000 records. | https://developer.salesforce.com/docs/platform/salesforce-cli-reference/guide/cli_reference_data_query.html | API version not applicable; command accepts `--api-version`; local CLI `@salesforce/cli/2.141.6` help checked | 2026-08-02 | Official documentation and local `sf data query --help` | Read-only use depends on SELECT-only SOQL; avoid broad customer data exposure. |
| `sf org list limits` returns max and remaining allocation for org limits. | https://developer.salesforce.com/docs/platform/salesforce-cli-reference/guide/cli_reference_org_list_limits.html | API version not applicable; command accepts `--api-version`; local CLI `@salesforce/cli/2.141.6` help checked | 2026-08-02 | Official documentation and local `sf org list limits --help` | Limit evidence is point-in-time and target-org specific. |
