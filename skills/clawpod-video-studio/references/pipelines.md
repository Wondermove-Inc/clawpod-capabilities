# Pipeline selection

Validated manifests in the pinned OpenMontage backend are the source of truth. Supported boundaries: animated-explainer, animation, avatar-spokesperson, character-animation, cinematic, clip-factory, documentary-montage, framework-smoke, hybrid, localization-dub, podcast-repurpose, screen-demo, and talking-head. State production, beta, or test stability. `documentary-montage` is permitted only when the documented `openmontage-documentary-category` patch adds `documentary` to the schema enum, its patch and patched-file digests match `upstream.lock.json`, and positive plus invalid-category validation tests pass. Never apply an undocumented silent patch. Distinguish reference inspiration from source editing and real-footage retrieval from generated motion.
